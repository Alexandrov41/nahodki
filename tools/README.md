# Инструменты сопровождения

## `node tools/check.mjs`

Проверка каталога перед публикацией. Занимает секунду.

- **целостность оригинала** — массивы `CATS` и `TOOLS` побайтово
  сверяются с `index.original.html`
- **перекрёстные ссылки** — связки, разборы моделей, карта решений
  и витрина не должны ссылаться на несуществующие находки
- **полнота данных** — у каждой находки есть адрес, у каждой рубрики
  шпаргалка, пометки доступа из известного списка
- **сетки** — число моделей и связок должно делиться на 2, 3 и 4,
  иначе в последнем ряду будет дыра

Возвращает код 1 при любой проблеме — годится для CI.

## `node tools/check.mjs --links`

То же плюс обход всех адресов каталога. Занимает около минуты.

Умеет отличать реальные проблемы от ложных:
- `401/403/405/406/429` — защита от ботов, не считается ошибкой
- российские сервисы недоступны с зарубежных адресов — в списке `GEO`
- если Node не смог, перепроверяет через `curl`

## `node tools/export.mjs`

Выгружает каталог в `tools.json` — плоская структура для внешнего
использования: находки с рубрикой, доступом, лимитом, задачами и
оценками. Пополнять каталог всё ещё нужно в `assets/js/data.js`,
JSON — это витрина данных, а не источник.
